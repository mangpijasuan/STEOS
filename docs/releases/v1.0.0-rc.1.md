# STEOS v1.0.0-rc.1 — release candidate preparation

Status: proposed prerelease for isolated staging only. Not a commercial launch.

## Scope
- Restaurant-branded storefront, pickup ordering and tracking, kitchen dashboard, menu and staff management.
- QR table ordering and till workflows, reporting and configurable pricing; enable only after restaurant acceptance.
- Stripe Connect integration requires sandbox certification; no live payments authorized.
- Centralized STEOS branding; internal package name, API routes and database identifiers retained.
- Docker deployment, separate migration credentials, health endpoints, bounded readiness responses and shared probes.
- Delivery, loyalty and recurring merchant billing remain outside the initial launch.

## Release gates
Before tagging: review version metadata, verify release PR CI and integrated main CI, obtain founder approval.
Before staging: isolated database, restricted app role, HTTPS, test-only payment credentials, migration and backup plan.
Before commercial launch: complete docs/LAUNCH_CHECKLIST.md, including real Stripe sandbox reconciliation, backup restore, restaurant acceptance and legal/trademark clearance.

## Known limitations
Smoke test uses a disposable privileged database account; it is not a production permission or load certification. Readiness response timeout does not forcibly cancel an outstanding database query. Real infrastructure, payment flows, physical devices and backup restoration remain unverified. No live payment or deployment authorization is implied.
